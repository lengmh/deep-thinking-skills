# v1.1.0 评估摘要

本公开快照复用固定 Cv2 包的既有验证结果，不重新评分，不把公开仓库的初始提交当成新的模型实验。

## 实现检查与实际任务

来源版本的完整单测为 151/151，离线合成校准为 44/44，包校验通过。单测和合成校准验证实现合同，不等于真实模型行为收益。公开分发另核查文件允许清单、来源字节、包 manifest、文档链接和秘密特征；实际结果随 Release 的 `RELEASE_VERIFICATION.md` 发布。

实际任务请求模型为 `gpt-6.1-sol`，effort 为 `max`，Codex CLI 为 `0.162.0-alpha.2`，环境为 Linux/WSL。A 不加载 Skill，C/Cv2 显式调用 Standard。候选使用新隔离会话；独立匿名评审核查一般证明、数值、实际图像和脚本副本。质量先封存，再开放开销记录。

## 可观察差异

T02 的 Cv2 使用有限支撑算子、Gram 证明和标准库符号检查；A/C 的一般性证明同样充分。T03 的逐字段来源断言增加可复现性，各组均完成核心核验。X07 的 C 使用代数双射，A/Cv2 使用小域枚举，Cv2 另给几何覆盖核验。X08 三组均识别二维轮廓、圆环和平行带；C 增加统一正交距离的十折几何检查。方法差异未形成评分差距。

T04 完成实际模型修正、物理与精度复验及导出核对；T06 完成标签泄漏修正和复验；T05 正确区分论文实测条件与目标场景外推。这些结果支持样本任务完成，不证明一般性性能优势。

## 来源关系与限制

- T03 的 C/Cv2 来自双答卷评审，A 来自后来重跑和单份评审；科学内容可比较，但不改写为同轮三份评分。
- T04 评分包括授权的传输故障后恢复；X08 最终评分发生一次原生重连后正常完成。原始分数及失败记录保留。
- 单个模型、单一 effort、有限题目、较少重复和满分效应限制区分能力；各题的预算、路由和环境跨批次并不完全一致。
- X08 复用固定 426 行匿名 CSV，与不可访问原始端点的字节等价性未核验。几何结构拟合不替代仅凭 x 预测 y 的独立泛化验证。
- 实际任务比较覆盖 Standard；本次未新增全模式 L3、跨宿主、Windows 原生或并发认证。历史版本的资格继续绑定历史包。

当前能确认 Cv2 保留了任务要求的关键核验并完成交付，已评分样本未观察到必要核验被削弱。尚未证实相对 C 或无 Skill 的质量、收敛或成本增益，也未证明一般性等效。

机器可读结果见 [evaluation-summary.json](evaluation-summary.json) 和 [SCORECARD.csv](SCORECARD.csv)。摘要保留来源评分文件哈希，未包含原始会话、完整图像或宿主配置，因此不能独立重放全部实验。
