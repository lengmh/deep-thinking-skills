# v1.1.0 评估结果

以下汇总 Cv2 的既有测试和原始评分。公开仓库发布时没有重新运行模型实验或修改评分。

## 测试方法

来源版本通过了 151/151 项单测、44/44 项离线合成校准和包校验。单测与合成校准检查实现是否符合规则，不能据此判断模型回答是否改善。文件范围、来源内容、manifest、文档链接和敏感信息的检查结果见 Release 附件 `RELEASE_VERIFICATION.md`。

实际任务请求模型为 `gpt-6.1-sol`，effort 为 `max`，Codex CLI 为 `0.162.0-alpha.2`，环境为 Linux/WSL。A 不加载 Skill，C/Cv2 显式调用 Standard。各答卷使用新的隔离会话，由独立评审在隐藏组别的情况下核查一般性证明、数值、实际图像和脚本副本。先固定质量评分，再查看开销记录。

## 答题方法的差异

T02 的 Cv2 使用有限支撑算子、Gram 证明和标准库符号检查；A/C 的一般性证明同样充分。T03 逐字段核对来源，并通过断言检查，提高了可复现性；各组均完成核心核验。X07 的 C 使用代数双射，A/Cv2 使用小域枚举，Cv2 另检查几何覆盖。X08 三组均识别二维轮廓、圆环和平行带，C 另用统一正交距离进行十折几何检查。这些方法差异没有形成评分差距。

T04 完成模型修正、物理与精度复验及导出核对；T06 完成标签泄漏修正和复验；T05 区分了论文的实测条件与目标场景的外推条件。这些答卷完成了相应任务，但不能据此推断一般性性能优势。

## 测试范围与限制

- T03 的 C/Cv2 由双答卷评审评分，A 来自后续重跑和单份评审。科学内容可以比较，但三份答卷并非同轮评分。
- T04 的评分包含经授权在传输故障后恢复的过程；X08 最终评审在一次原生重连后正常完成。原始分数和失败记录均保留。
- 测试只使用一个模型和一个 effort，题目有限、重复次数较少，满分也限制了区分能力。各题的预算、路由和环境在不同批次间并不完全一致。
- X08 使用固定的 426 行匿名 CSV，未核验它与无法访问的原始端点是否逐字节一致。几何结构拟合不能替代仅凭 x 预测 y 的独立泛化验证。
- 实际任务比较只覆盖 Standard。这轮没有新增三种模式的完整宿主测试、跨宿主、Windows 原生或并发测试；较早版本的测试结果仅适用于当时的包。

已评分样本中，Cv2 保留了任务所需的关键核验并完成交付，未观察到必要核验被削弱。现有结果尚未证实它相对 C 或无 Skill 的质量、收敛或成本优势，也未证明一般性等效。

机器可读结果见 [`evaluation-summary.json`](evaluation-summary.json) 和 [SCORECARD.csv](SCORECARD.csv)。摘要保留了来源评分文件的哈希，但不包含原始会话、完整图像和宿主配置，无法单独用于重放全部实验。
